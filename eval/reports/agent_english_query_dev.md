# Agent 英文检索词实验（dev-only）

## 范围

- 数据集：`eval/agent_dev.jsonl`（20 题，其中 8 道概念题用于 source 指标）。
- 对照组：原始 `search_docs` 工具说明。
- 实验组：工具说明要求模型用英文关键词作为 `query`，并尽量采用文档英文术语。
- 每组独立运行 3 次；不读取或运行冻结 test 集。
- 本实验不预先改变默认行为，结果产物写入被忽略的 `eval/outputs/`。

## 预注册采纳门槛

以下条件必须同时满足，才考虑把英文检索词变体设为默认：

1. 实验组概念题 Top-1 平均命中数比对照组至少多 **2 题（共 8 题）**，即 Top-1
   平均率至少提升 **0.25**。
2. 实验组来源命中率均值不低于对照组。
3. 实验组必需工具召回均值不低于对照组。

任一条件不满足，就保持默认关闭，只记录 dev-only 结果。多余调用率和平均 steps 同时报告，
但不作为本次预注册的硬门槛。

六次运行均完成 20/20 题，`n_errors=0`。Top-1 与来源命中只统计 8 道概念题；
其余指标统计全部 20 题。

## 门槛判断

- Top-1 平均命中数提升 `7.33 - 3.33 = 4.00` 题，高于预注册的 2 题门槛。
- 来源命中率从 95.8% 提升到 100%，没有下降。
- 必需工具召回均为 100%，没有下降。

因此英文检索词变体**达到全部预注册采纳门槛**。这是小规模 dev-only 结论，未触碰冻结
test 集，不应表述为泛化结论；原始 answer、trace 与检索结果保存在被忽略的
`eval/outputs/agent_dev_{baseline,english_query}_run{1,2,3}.json`。

用户确认按预注册门槛采纳：`run_agent` 现默认启用英文检索词说明，同时保留
`english_search_query=False` 以便显式关闭；这不改变 `search_docs` 的检索实现。
